music_noteNo account, no login

Swifty, your music, local.

a local music player for desktop, built with Qt Quick on top of a Rust audio core. it plays the music files on your computer: no account and no login. it follows Material 3 Expressive (heavy inspo from end4). runs on linux (made for wayland and hyprland), macos and windows.

swifty is a fork of Swiftify by shred0s, which was a spotify client. everything spotify is gone from this fork: the player only knows your own files. forked by ImAlekzzz. don’t expect frequent updates, maybe once in a while.

downloadInstall

there are no prebuilt packages in the repo: swifty is built from source, and the scripts in tools/ make packages for each system (build-debian.sh, build-rpm.sh, build-linux-tarball.sh, build-macos-dmg.sh and build-windows.ps1). you need Qt 6.10+, QCoro, CMake, Ninja, a C++20 compiler and Rust. build in a fresh folder.

git clone https://github.com/ImAlekzzz/swifty.git
cd swifty
Arch Linuxexpand_more
cd packaging/arch
makepkg -si
Linux, macOS (cmake)expand_more
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF -DCMAKE_INSTALL_PREFIX="$HOME/.local"
cmake --build build
cmake --install build
Windowsexpand_more
in PowerShell:
.\tools\build-windows.ps1
move the folder it makes to a place you will keep it, such as %LOCALAPPDATA%\Programs\Swifty, and run bin\swifty.exe from there.
Fedora, from sourceexpand_more
./tools/build-rpm.sh --install-deps
sudo dnf install dist/swifty-*.rpm
Debian and Ubuntuexpand_more
./tools/build-debian.sh --install-deps
Any Linux, with Qt includedexpand_more
./tools/build-linux-tarball.sh --qt ~/Qt/6.10.0/gcc_64
macOS, from sourceexpand_more
./tools/build-macos-dmg.sh

settings_remoteCommand line

only one swifty runs at a time. launching it again passes the command to the one that’s running, so these work great as keybinds:

swifty --immersive    # open the immersive player
swifty --play-pause   # play or pause
swifty --next         # next song
swifty --previous     # previous song

swifty:// links do the same from a browser or a launcher:

<a href="swifty://play-pause">Play or pause</a>

known links:

play-pausenextpreviousimmersiveclose-immersiveplay-recenthomeplaylistssongsfavouritesalbumsartistsback

a link can never change a setting or name a file.

shieldPrivacy

swifty has no account, no analytics and no telemetry, and the author receives nothing. it keeps its settings, playlists and caches on your own computer (~/.config/Swifty, ~/.local/share/Swifty and ~/.cache/Swifty on linux).

the only things that leave your computer are the lookups below, and both can be turned off in the settings. every request also carries your IP address and a Swifty/<version> user agent.

lyrics

Lyrics

sent to LRCLIB, then MusicBrainz: title, main artist, album and length (LRCLIB), title and main artist (MusicBrainz).

person

Artist pictures

sent to Discogs: the artist’s name, and your token.

Discord rich presence talks to the Discord app on your own computer, not over the network by swifty. the full privacy policy and the terms of use are in the docs.

helpTroubleshooting

swifty prints nothing to the terminal when all is well. to see what it is doing, start it with SWIFTY_DEBUG=1:

SWIFTY_DEBUG=1 swifty 2>&1 | grep -a "^swifty "
playlists don’t survive a restartexpand_more
Qt’s SQLite driver is missing (on debian/ubuntu it’s libqt6sql6-sqlite).
nothing shows on Discordexpand_more
the Discord desktop app must be running, with Share my activity on.
it runs an old version after an updateexpand_more
quit it first (pkill swifty).

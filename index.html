Swifty, your music, local.

A local music player for Wayland, in Material 3. It plays the music on your computer, with a Rust audio core and a Qt Quick interface. A fork of Swiftify by addenator, with everything of Spotify removed.

Build it yourself

Arch and Debian have no download: build them from source with the scripts below, and any other system can too. Building needs the network, because the interface and icon fonts are downloaded (each is checked against a hash). Qt 6.10 is what the source asks for.

git clone https://github.com/ImAlekzzz/swifty.git
cd swifty
Arch Linuxexpand_more
cd packaging/arch
makepkg -si
Fedora, from sourceexpand_more
./tools/build-rpm.sh --install-deps
sudo dnf install dist/swifty-*.rpm
Debian and Ubuntuexpand_more
./tools/build-debian.sh --install-deps
Any Linux, with Qt includedexpand_more
Makes the same tarball as the download.
./tools/build-linux-tarball.sh --qt ~/Qt/6.10.0/gcc_64
macOS, from sourceexpand_more
./tools/build-macos-dmg.sh
Windows, from sourceexpand_more
In PowerShell:
.\tools\build-windows.ps1
Move the folder it makes to a place you will keep it, such as %LOCALAPPDATA%\Programs\Swifty, and run bin\swifty.exe from there.

checklistBefore you start

library_music

Your music

Add a folder or files from the home screen or the settings.

database

Qt’s SQLite driver

Swifty keeps its playlists and library in SQLite. Arch, Fedora and the Qt installer include the driver. On Debian and Ubuntu install libqt6sql6-sqlite.

key

Artist pictures (optional)

Make a free personal token at discogs.com/settings/developers and paste it in Settings, Files, Artist Pictures.

sports_esports

Discord (optional)

It works out of the box. You need the Discord desktop app running, and activity sharing on in Discord’s Activity Privacy settings. To show your own name instead, paste your own Application ID in Settings, Discord.

settings_remoteControl it from outside

Only one Swifty runs at a time. Starting it again passes the command to the one that is running, so these work as keybinds:

swifty --immersive
swifty --play-pause
swifty --next
swifty --previous

The same commands work as links, for a browser, a bookmark or a launcher:

<a href="swifty://play-pause">Play or pause</a>

Known links:

play-pausenextpreviousimmersiveclose-immersiveplay-recenthomeplaylistssongsfavouritesalbumsartistsback

A link can never change a setting or name a file.
